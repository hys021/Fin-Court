# FIN-COURT  
### 소비를 재판하는 AI 소비 판단 서비스

> “소비를 기록하지 말고, 재판받게 하자.”

---
# 📦 실행 방법

1. GitHub 저장소 우측 상단의 `< > Code` 버튼을 클릭합니다.

2. `Download ZIP`을 선택하여 프로젝트 파일을 다운로드합니다.

3. 다운로드한 ZIP 파일의 압축을 해제합니다.

4. 압축 해제 후 생성된 `아이디어톤` 폴더로 이동합니다.

5. 폴더 내부의 `MVP_FIN.html` 파일을 실행하면 서비스를 확인할 수 있습니다.

---

## 📌 프로젝트 소개

FIN-COURT는 사용자의 소비를  
“재판” 형식으로 분석하여 충동소비를 줄이는  
행동 개입형 서비스입니다.

기존 금융 서비스가 소비 이후의 기록과 관리에 집중했다면,  
FIN-COURT는 소비 직전 순간에 개입하여  
사용자가 한 번 더 생각하고 판단할 수 있도록 돕습니다.
